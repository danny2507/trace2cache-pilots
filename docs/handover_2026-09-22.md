## 3. Latest experiment — event-chain SFT (closed 2026-09-22)

### 3.1 Why it was run

Ask-events Gate 0: frozen 3B invents compact CALL/BRANCH/LINE/STATE then stdout. No gold trace in the prompt. Last fenced block = stdout.

| | ask_events | code_input | gold trace_text |
| --- | ---: | ---: | ---: |
| correct / 128 | 5 | 12 | 25 |

Call **`gate0_sft_justified`**: the model can read events it cannot invent. Tight SFT A/B was justified.

### 3.2 Design

Same `ask_events` prompt for both LoRAs. Train on disjoint 320. Eval last-fence on frozen 128.

- `sft_stdout`: teacher-force stdout fence only.
- `sft_events`: teacher-force compact gold events (cap 24) then stdout fence.

LoRA r=16, alpha=32, dropout 0.05, modules q/k/v/o, 1280 steps, lr 1e-4, accum 4, max_new_tokens 512, max_sequence_tokens 4096, seed 1001. 7,372,800 trainable params each.

Compact teacher strips `__builtins__` / `__name__` via identifier scan (`_IDENT_EQ`), not brace parsing (truncated dumps break braces). Redact gold from event lines only if `len(gold_n) ≥ 2` (do not redact single-digit stdout out of `i=1`).

def render_ask_events_prompt(example: SimExample, *, cap: int = NATIVE_CAP) -> str:
    """Code+stdin; the model must invent compact events, then stdout. No gold trace."""
    stdin = example.stdin.rstrip("\n")
    roles = "\n".join(f"{role}: ..." for role in ASK_EVENT_ROLES)  # CALL, BRANCH, LINE, STATE
    return f"""Predict the exact stdout of this Python program on the given input.

First write a compact execution trace, one event per line, using only these roles:
{roles}
Write at most {cap} events. Do not write TEST, PASS, FAIL, RETURN, or END_TEST. Do not put the final stdout in the trace.

Then write the exact stdout inside one markdown code block. No other explanation.

Program:
```python
{example.source.rstrip()}
```

Input:
```
{stdin}
```
"""
```

Teacher:

```python
def user_state_fields(state: str) -> str:
    """Keep user locals. Dunder dumps may be truncated, so do not brace-parse them."""
    matches = list(_IDENT_EQ.finditer(state or ""))
    kept = []
    for index, match in enumerate(matches):
        name = match.group(1)
        if name.startswith("__"):
            continue
        start = match.end()
        end = matches[index + 1].start() if index + 1 < len(matches) else len(state)
        value = state[start:end].strip().rstrip(",")
        if value:
            kept.append(f"{name}={value}")
    return ", ".join(kept)

def sft_stdout_target(example: SimExample) -> str:
    return f"```\n{normalize_output(example.gold_stdout)}\n```"

def sft_events_target(example: SimExample, *, cap: int = NATIVE_CAP) -> str:
    events = gold_ask_events_text(example, cap=cap)
    if not events.strip():
        raise ValueError(f"no compact events for {example.example_id}")
    return f"```\n{events}\n```\n\n{sft_stdout_target(example)}"
```

## 6. How to eval a new idea (copy this)

1. Write a kill rule **before** training. McNemar on the frozen 128, p<0.05, left_only > right_only.
2. Control must be the strongest honest baseline, not a weakened one (do not hide stdin; do not drop the public test from repair prompts).
3. If the claim is a channel: shuffle (and usually corruption) must drop. Identical pass/fail under shuffle = unused prefix.
4. Text Gate 0 first. If gold text does not beat the no-evidence / code_input control, **do not encode it**.
5. Never train on the frozen 128. Assert disjoint `example_id`, `task_id`, `source_hash`.
6. Verify cohort shas before writing artifacts.
7. Last fenced block is stdout for sim; hidden tests are Repair@1 for repair.
8. `.venv/bin/python`. `PYTHONPATH` includes `src` (and `scripts` when importing `run_execution_sim.load_model`).
